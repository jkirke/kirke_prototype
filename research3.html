«Journey Mapping I»

This Journey Mapping examines the senior staff software engineer’s role across the development and release of a single product. This visualization represents a generalized product cycle, as opposed to a specific product case study.

The product cycle consists of the following stages: planning, requirement analysis, design, development, testing, deployment, maintenance, and retirement

In the planning phase, the project manager organizes the project, stakeholders approve budgets, and the architect evaluates the project’s technical feasibility.

In the requirement analysis phase, the architect analyzes technological needs and constraints. Simultaneously, product owners interact with stakeholders and understand business needs. Software testers identify the product’s testability criteria.

In the design phase, the architect creates project documentation for the developers. The UX team maps the design systems and conducts user research. If necessary, the database administrator designs database structures for the product. The security engineer ensures the product is compliant with security protocols. Since products are designed with security as opposed to made secure after creation, compliance is important early on.

In the development phase, developers begin writing and integrating source code for the product. The developers may make changes to the initial documentation provided by the architect.
