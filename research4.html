Research Methods

«Journey Mapping II»

In the testing phase, software testers begin testing the developed product. Software testers and developers exchange information regarding product functionality. Documentation may continue to change and issues are continuing to be opened. The end of the development phase is marked by the DCUT (development cut). Developers are not allowed to add additional code and software testers conduct more robust testing.

In the deployment phase, developers manage environments and rollout strategies while operations monitor server and traffic information. The product owner coordinates communication with end users. The tested software is released into the production environment.

In the maintenance phase, support engineers manage user tickets and bug reports. Maintenance developers create patches to the product and a monitoring team tracks system health.

In the retirement phase, software is phased out.
